# M1 驗收步驟

對應 implementation plan 第 10、11 節。建議先用一個自己開的 Meet 會議（或任一有聲音的 YouTube 分頁）試 10 分鐘，再用在真實課程上。

| # | 步驟 | 預期結果 | 結果 |
| --- | --- | --- | --- |
| T1 | 在 Meet 分頁點圖示 →「開始錄製此分頁」，錄 10 分鐘後按「停止並存檔」 | 下載資料夾出現 `.webm`，用 Chrome 或 VLC 開啟時長正確、可拖曳進度條、影音同步 | |
| T2 | 錄製中切到其他分頁 5 分鐘 | 影片中該段畫面持續更新，沒有黑畫面或定格 | |
| T3 | 錄製中把 Chrome 視窗縮到最小 | 同 T2 | |
| T4 | 錄製中聽喇叭／耳機 | 課程聲音正常；停止後 Meet 分頁自己發聲 | |
| T5 | 錄製中暫停 1 分鐘再繼續 | 檔案中沒有暫停那一段，總時長扣除暫停 | |
| T6 | 錄製中直接關閉 Meet 分頁 | 自動存檔並跳出通知，檔案可播放 | |
| T7 | 錄製開始後觀察畫面 | 錄製視窗自動最小化；Meet 分頁標題出現 `● REC │`、favicon 變紅點；工具列 badge 為紅底 `REC` | |
| T8 | 錄製 1 小時以上 | 在「活動監視器」觀察 Chrome 記憶體沒有持續增長；CPU 佔用可接受 | |

## 需要回報的數字

- 1080p 錄製時的 CPU 佔用（活動監視器中 Chrome 相關程序），以及 Meet 是否掉幀。
- 4 Mbps 下投影片小字是否清楚。
- 若錄製視窗出現「瀏覽器暫停了聲音回放」提示，請告訴我。

## 有問題時

在 `chrome://extensions` 的 Tab Recorder 卡片上可以打開「service worker」的 DevTools；錄製視窗可以按右鍵 →「檢查」看 console 錯誤訊息。
