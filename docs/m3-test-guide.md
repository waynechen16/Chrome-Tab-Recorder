# M3 驗收步驟（指定資料夾與設定頁）

對應 implementation plan 第 7、8、10 節。更新方式：`chrome://extensions` → Tab Recorder 的重新整理圖示。

| # | 步驟 | 預期結果 | 結果 |
| --- | --- | --- | --- |
| T1 | popup 下方「設定」→ 儲存位置選「指定資料夾」→ 選一個資料夾並允許寫入 | 設定頁顯示資料夾名稱與「已授權寫入」；popup 開始按鈕下方顯示「存到：『資料夾名』」 | |
| T2 | 錄 1 分鐘後停止 | 檔案直接出現在該資料夾；通知標題為「錄製已存到『資料夾名』」 | |
| T3 | 檔名樣板改成 `{title}`，同一分頁錄兩次 | 第二個檔案自動命名為 `… (1).webm`，不會覆蓋 | |
| T4 | 完全結束 Chrome 再開，直接開始錄製 | 若需要重新授權：錄製視窗不會自動最小化，並顯示「點這裡授權寫入…」；點了之後視窗自動最小化，檔案存到資料夾 | |
| T5 | T4 的情況下不點授權，直接停止 | 錄影改存到下載資料夾，通知標題為「錄製已存檔（改存到下載資料夾）」，popup 說明原因 | |
| T6 | 解析度選 720p、幀率 15 fps 錄製 | 檔案為 1280×720、15 fps（可用 VLC 的「媒體資訊」或 QuickTime 以外的播放器查看） | |
| T7 | 解析度選「跟隨分頁」錄製 | 檔案尺寸等於 Meet 分頁內容區的實際像素（Retina 螢幕為兩倍），不會變形 | |
| T8 | 設定頁「恢復預設值」 | 品質、檔名、視窗設定回到預設；儲存資料夾與麥克風選擇不變 | |
| T9 | 位元率改 2 Mbps 與 8 Mbps 各錄 5 分鐘投影片內容 | 比較檔案大小與小字清晰度，決定你的預設值 | |

## 需要回報

- T4 在你的 Mac 上是否每次重開 Chrome 都要重新授權（取決於 Chrome 版本與你在授權提示中是否選了「每次造訪都允許」）。
- T9 你覺得合適的位元率，我可以把它設成預設。
