# M2 驗收步驟（麥克風混音）

對應 implementation plan 第 6、10 節。建議戴耳機測試。

| # | 步驟 | 預期結果 | 結果 |
| --- | --- | --- | --- |
| T0 | 點 popup 下方「設定」→「授權並測試麥克風」，Chrome 跳出權限提示時按「允許」 | 狀態顯示「已授權」，對麥克風說話時音量條跳動；下拉選單列出你的麥克風 | |
| T5 | 開始錄製後，在 popup 開關「混入我的麥克風」5 次，每次開著時說幾句話 | 檔案只有一條連續音軌，開的時段聽得到你的聲音，關的時段聽不到；錄製不中斷 | |
| T5b | 在錄製視窗（按「顯示錄製視窗」叫出）點「麥克風」按鈕切換 | 與 popup 狀態同步；藍色音量條在開啟時跳動 | |
| T6 | 到 Chrome 網站設定把麥克風改為封鎖，再開始錄製並打開麥克風 | 錄製繼續；popup 顯示「尚未授權麥克風」與開啟設定頁的按鈕 | |
| T6b | 錄製中拔掉 USB／藍牙麥克風 | 麥克風自動關閉並提示「裝置已中斷連線」；錄製不中斷；接回後可再打開 | |
| T7 | 在 popup 未錄製時打開「開始時混入我的麥克風」，再開始錄製 | 錄製一開始就混入麥克風；下次打開 popup 開關仍記得這個選擇 | |
| T8 | 不戴耳機、用喇叭錄製並打開麥克風 | 聽聽看錄音裡課程聲音是否有回音或重疊；若明顯，之後一律戴耳機 | |

## 需要回報

- T8 的回音程度（Chrome 的回音消除對「同一個 Chrome 播放的聲音」通常有效，但因機器而異）。
- 麥克風音量與課程音量的相對大小是否合適；若你的聲音太小或太大，下一版可加一個麥克風音量滑桿。
