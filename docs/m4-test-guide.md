# M4 驗收步驟（當機復原、自動分段、問題紀錄）

對應 implementation plan 第 7、9、10 節。更新方式：`chrome://extensions` → Tab Recorder 的重新整理圖示。

| # | 步驟 | 預期結果 | 結果 |
| --- | --- | --- | --- |
| T10 | 錄製 2 分鐘後，直接關閉錄製視窗（出現確認時選「離開」） | popup 顯示錯誤並提示修復；按「確定」後，popup 出現「有 1 個未完成的錄製，按此修復」 | |
| T11 | 錄製 2 分鐘後，用「活動監視器」強制結束 Google Chrome，再重開 Chrome | 設定頁頂端出現「未完成的錄製」；按「修復並存檔」後，檔案存到你設定的位置，時長約為錄到的長度，可拖曳播放（最後約 1 秒可能遺失） | |
| T12 | 連續錄製 2 小時以上 | 「活動監視器」中 Chrome 記憶體沒有持續增長；檔案可正常播放與拖曳 | |
| T13 | 設定頁「自動分段」選 30 分鐘，錄 70 分鐘 | 產生 `_part1`、`_part2`、`_part3` 三個檔案，前兩個約 30 分鐘；接縫處影音連續，沒有明顯跳躍 | |
| T14 | 在設定頁「未完成的錄製」按「刪除」 | 確認後該筆消失，空間釋放 | |
| T15 | 做完 T10、T11 後看設定頁「最近的問題紀錄」 | 有「錄製視窗被關閉」等紀錄，時間正確；「清除」可清空 | |
