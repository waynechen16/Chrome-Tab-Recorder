# Chrome Tab Recorder

錄製 Chrome 分頁影音（例如 Google Meet 線上課程）的 Chrome extension（Manifest V3，個人使用）。

目前進度：**M5 實戰驗證中**（v0.5.0）。功能：一鍵錄分頁、暫停／繼續、錄製狀態標示、麥克風混音（錄製中隨時開關）、存到下載資料夾或指定資料夾、完整設定頁、自動分段、當機後修復、問題紀錄、課前檢查、錄製品質統計。第一次在真實課程使用前，請看 [實戰驗證手冊](docs/m5-field-test.md)。

## 安裝（載入未封裝擴充功能）

需要 Node.js 20 以上。

```bash
npm install
npm run build
```

1. Chrome 開啟 `chrome://extensions`，右上角打開「開發人員模式」。
2. 按「載入未封裝項目」，選擇 `dist/chrome-mv3` 資料夾。
3. 建議把 Tab Recorder 圖示釘選到工具列。

之後改了程式碼，重新 `npm run build`，再到 `chrome://extensions` 按 Tab Recorder 的重新載入即可。**錄製中不要重新載入 extension**，否則錄製會中斷。

## 使用方式

1. 在要錄的分頁（例如 Meet 課程）點工具列的 Tab Recorder 圖示，按「開始錄製此分頁」。
2. 右下角會出現一個小的錄製視窗，開始錄製後自動最小化；錄製中**不要關閉它**。
3. 錄製狀態會同時顯示在：
   - Meet 分頁標題前綴 `● REC │`（暫停時 `‖ PAUSED │`）與紅點／黃色 favicon
   - 工具列圖示 badge：紅底 `REC`、黃底 `‖`
   - 錄製視窗的標題與計時
4. 再點圖示可暫停／繼續、停止並存檔。關閉被錄的分頁也會自動停止並存檔。
5. **麥克風**：第一次使用前，點 popup 下方「設定」→「授權並測試麥克風」授權一次。之後 popup 的「混入我的麥克風」開關在錄製前決定初始狀態，錄製中可隨時切換，不會中斷錄製。建議戴耳機。
6. 檔案預設存到下載資料夾，檔名為 `{分頁標題}_{日期}_{時間}.webm`，存檔後會跳出通知。在「設定」可改成存到指定資料夾，並調整解析度、幀率、位元率與檔名規則。若無法寫入指定資料夾，會自動改存到下載資料夾。
7. **萬一中斷**（Chrome 當機、錄製視窗被關閉）：錄到的內容不會遺失。popup 會提示「有 N 個未完成的錄製」，到設定頁按「修復並存檔」即可。長時間課程可在設定頁開啟「自動分段」。

若錄製視窗顯示「瀏覽器暫停了聲音回放」，打開錄製視窗點一下提示即可恢復聽到課程聲音（錄音本身不受影響）。

錄製他人參與的會議或課程前，請先取得同意。

## 常見問題

**錄製中聽不到課程聲音？** 錄製視窗若顯示「瀏覽器暫停了聲音回放」，打開錄製視窗點一下提示即可，錄音本身不受影響。

**popup 顯示的 fps 很低？** 投影片靜止時 Chrome 不會送新畫面，fps 低是正常的，播放不受影響。只有出現「電腦來不及編碼」警告才需要調整設定（改 VP8、720p 或 15 fps）。

**錄影存到哪裡？** 設定頁「儲存位置」決定；popup 開始按鈕下方也會顯示。若無法寫入指定資料夾，會自動改存到下載資料夾，通知會說明原因。

**Chrome 當機或不小心關了錄製視窗？** 內容不會遺失。popup 會提示「有 N 個未完成的錄製」，到設定頁按「修復並存檔」。

**要回報問題？** 設定頁「最近的問題紀錄」→「複製診斷資訊」，連同狀況描述一起提供。

## 開發

```bash
npm run dev        # WXT 開發模式（會開一個載入 extension 的 Chrome）
npm test           # 單元測試（WebM Duration 修補用真實 Chromium 錄出的檔案驗證，需 ffprobe）
npm run typecheck
```
