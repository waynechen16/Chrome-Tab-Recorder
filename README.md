# Chrome Tab Recorder

錄製 Chrome 分頁影音（例如 Google Meet 線上課程）的 Chrome extension（Manifest V3）。

- 一鍵錄製目前分頁的畫面與聲音（`chrome.tabCapture`）
- 麥克風可在錄製中隨時開關
- 輸出 WebM（VP9/VP8 + Opus），長時間錄製不佔記憶體
- 可指定儲存資料夾，預設存到下載資料夾
